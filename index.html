Guía del taller práctico de arreglos

En esta guía construirás paso a paso tres ejercicios: registro de nombres, inventario de productos y sistema de ventas. El ejercicio 4 es un reto de búsqueda de estudiantes que desarrollarás por tu cuenta.

1. Preparar el proyecto

La guía es este archivo index.html. Crea una carpeta aparte llamada taller-array para los archivos del proyecto y no reemplaces la guía con el menú de ejemplo.

  1. Crea una carpeta llamada taller-array.
  2. Dentro de ella, crea los archivos HTML y la carpeta js con esta estructura. El ejercicio 4 queda para que lo completes:
taller-array/
├── index.html
├── ejercicio1.html
├── ejercicio2.html
├── ejercicio3.html
├── ejercicio4.html
└── js/
    ├── ejercicio1.js
    ├── ejercicio2.js
    ├── ejercicio3.js
    └── ejercicio4.js
  1. Abre la carpeta completa en Visual Studio Code.
  2. Guarda el menú principal en taller-array/index.html. Escribe el HTML de cada ejercicio en su archivo y el JavaScript correspondiente dentro de js.
  3. Para probar el proyecto, abre index.html en un navegador y entra a cada ejercicio.

2. Conceptos que usarás

  • Un arreglo guarda varios valores en una sola variable, por ejemplo: let nombres = [];.
  • push(valor) agrega un elemento al final del arreglo.
  • document.getElementById("...") obtiene un elemento HTML por su id.
  • .value lee o cambia el valor de un campo de entrada.
  • .textContent y .innerHTML permiten actualizar contenido de la página.
  • parseFloat() y parseInt() convierten texto ingresado en números; toLocaleString() presenta un número con separadores de miles.
  • forEach() permite ejecutar una acción para cada elemento de un arreglo.
  • Una función agrupa instrucciones para ejecutar una tarea.
  • En este proyecto, cada botón usa type="button" y llama a una función con onclick, por ejemplo: <button type="button" onclick="miFuncion()">Agregar</button>.
  • Los id del HTML y los consultados en JavaScript deben coincidir exactamente.

Paso 2: programar la lógica

En js/ejercicio1.js:

  1. Crea un arreglo vacío para guardar los nombres.
  2. Obtén el campo, la lista y el contador por sus id.
  3. En agregarNombre(), lee el campo, quita espacios sobrantes y convierte el texto a mayúsculas.
  4. No agregues el nombre si está vacío o ya existe.
  5. Si es válido, agrégalo con push, limpia el campo y llama a mostrarNombre().
  6. En mostrarNombre(), recorre el arreglo y actualiza la lista y el total.
let listaNombres = [];
function agregarNombre() {
    let nombre = document.getElementById("nombre").value.trim().toUpperCase();

    if (nombre === "") {
        alert("Ingrese el nombre");
        return;
    }

    else if (listaNombres.includes(nombre)) {
        alert(`El nombre ${nombre} ya está registrado`);
        return;
    }
    else{

        listaNombres.push(nombre);
        document.getElementById("nombre").value = "";
        mostrarNombre();
    }
}

function mostrarNombre() {

    let lista = document.getElementById("lista");
    let cantidad = document.getElementById("cantidad");
    lista.innerHTML = "";

    for (let i = 0; i < listaNombres.length; i++) {
        lista.innerHTML += `<li>${listaNombres[i]}</li>`;
    }

    cantidad.textContent = `Total nombres: ${listaNombres.length}`;
}

Paso 3: probar

  • Agrega un nombre y comprueba que aparezca en la lista.
  • Intenta agregar el mismo nombre con mayúsculas o minúsculas diferentes.
  • Intenta agregar el campo vacío y verifica que se muestre el mensaje.
  • Comprueba que el total cambie después de cada nombre válido.

Paso 2: programar la lógica

En js/ejercicio2.js, cada producto será un objeto guardado en un arreglo. El subtotal se calcula multiplicando el precio por la cantidad:

let listaProductos = [];

function agregarProducto() {
    let producto = document.getElementById("producto").value.trim();
    let precio = parseFloat(document.getElementById("precio").value);
    let cantidad = parseInt(document.getElementById("cantidad").value, 10);

    if (producto === "" || isNaN(precio) || isNaN(cantidad)) {
        alert("Llene todos los campos");
        return;
    }

    listaProductos.push({
        nombre: producto,
        precio: precio,
        cantidad: cantidad
    });

    document.getElementById("formulario").reset();
    mostrar();
}

function mostrar() {
    let tabla = document.getElementById("tabla");
    let total = document.getElementById("total");
    let totalNuevo = 0;

    tabla.innerHTML = "";

    for (let i = 0; i < listaProductos.length; i++) {
        let subtotal = listaProductos[i].precio * listaProductos[i].cantidad;

        tabla.innerHTML += `<tr>
            <td>${listaProductos[i].nombre}</td>
            <td>${listaProductos[i].precio}</td>
            <td>${listaProductos[i].cantidad}</td>
            <td>${subtotal}</td>
        </tr>`;

        totalNuevo += subtotal;
    }

    total.textContent = `Total: ${totalNuevo}`;
}

Paso 3: probar

  • Registra varios productos con precios y cantidades diferentes.
  • Verifica el subtotal de cada producto y el total del inventario.
  • Intenta dejar un campo vacío y observa la validación del navegador.
  • Comprueba que el formulario se limpie después de agregar un producto.

Paso 2: programar la lógica

En js/ejercicio3.js, guarda los productos en un arreglo. El código calcula los indicadores, registra productos y actualiza la tabla con los filtros seleccionados:

let listaProductos = [
    { id: 1, nombre: "Teclado", categoria: "Accesorios", precio: 85000, stock: 15 },
    { id: 2, nombre: "Mouse", categoria: "Accesorios", precio: 45000, stock: 20 },
    { id: 3, nombre: "Monitor", categoria: "Tecnología", precio: 650000, stock: 4 }
];

let totalProductos = listaProductos.length;
document.getElementById("totalProductos").innerText = totalProductos;

let valorInventario = 0;
for (let i = 0; i < listaProductos.length; i++) {
    valorInventario += listaProductos[i].precio * listaProductos[i].stock;
}
document.getElementById("valorInventario").innerText = valorInventario.toLocaleString();

let productoCaro = listaProductos[0].nombre;
let precioMayor = listaProductos[0].precio;

for (let i = 1; i < listaProductos.length; i++) {
    if (listaProductos[i].precio > precioMayor) {
        productoCaro = listaProductos[i].nombre;
        precioMayor = listaProductos[i].precio;
    }
}

document.getElementById("productoCostoso").innerText =
    `${productoCaro} - ${precioMayor} `;

let productoPocoStock = "";
for (let i = 1; i < listaProductos.length; i++) {
    if (listaProductos[i].stock < 10) {
        productoPocoStock = listaProductos[i];
    }
}

document.getElementById("pocoStock").innerText =
    `${productoPocoStock.nombre} - ${productoPocoStock.stock} unidades`;

let tablaProductos = document.getElementById("tablaProductos");
listaProductos.forEach(producto => {
    const fila = tablaProductos.insertRow();
    [producto.id, producto.nombre, producto.categoria, producto.precio.toLocaleString(), producto.stock]
        .forEach(valor => fila.insertCell().textContent = valor);
});

function agregarProducto() {
    event.preventDefault();
    let id = document.getElementById("idProducto").value;
    let nombre = document.getElementById("nombre").value;
    let categoria = document.getElementById("categoria").value;
    let precio = parseFloat(document.getElementById("precio").value);
    let stock = parseInt(document.getElementById("stock").value);
    let nuevoProducto = { id, nombre, categoria, precio, stock };
    listaProductos.push(nuevoProducto);
    actualizarTabla();
}

function actualizarTabla() {
    let tablaProductos = document.getElementById("tablaProductos");
    listaProductos.forEach(producto => {
        const fila = tablaProductos.insertRow();
        [producto.id, producto.nombre, producto.categoria, producto.precio.toLocaleString(), producto.stock]
            .forEach(valor => fila.insertCell().textContent = valor);
    });
}

6. Ejercicio 4: Registro de citas para un consultorio veterinario

En ejercicio4.html, crea un sistema de registro de citas para un consultorio veterinario. Deben construir la estructura HTML y la lógica en JavaScript para registrar citas médicas con la siguiente información:

  • Fecha de la cita.
  • Nombre de la mascota.
  • Tipo de mascota: perro, gato o conejo.
  • Raza de la mascota.
  • Edad de la mascota.
  • Tipo de consulta: cita, baño y estética, vacunación o urgencia.

Requisitos:

  • Crear un formulario con los campos anteriores.
  • Validar que todos los campos sean obligatorios.
  • Validar que la fecha no sea anterior a la fecha actual.
  • Comprobar que se seleccione una opción válida en cada lista desplegable.
  • Evitar registros vacíos y mostrar mensajes claros cuando falten datos, la edad sea inválida o la fecha sea incorrecta.
  • Guardar cada cita y mostrarla en una tabla con toda la información correspondiente.
  • La tabla debe incluir: fecha, nombre de la mascota, tipo de mascota, raza, edad y tipo de consulta.
  • Organizar el código en funciones y manejar los eventos con JavaScript.
  • Diseñar una interfaz simple, ordenada y funcional.
